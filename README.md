# Shelf

Where an agency parks every tool it built for a client, on one link the client can use.

## Status

Spec and design only. No application code yet. Build starts at slice 0 in the PRD.

## Docs

| File | What it is |
|---|---|
| `SHELF-PRD.html` | The spec. Supersedes the handoff wherever they disagree. Open it in a browser. |
| `SHELF-VALIDATION.html` | Market validation and the review that produced the agency-first inversion. |
| `SHELF_HANDOFF.md` | The original brief. Kept for provenance. Do not build from it directly. |
| `design/` | Seven screen artboards as Design Component files. |

## Design canvas

`design/*.dc.html` are the artboards, `design/canvas.json` is the layout.
`design/shelf-v1-screens.html` is generated from them and is gitignored.

Published canvas: https://claude.ai/code/artifact/dbb4cf43-d929-45cd-90c2-f352abc1ab08

If the canvas has been edited and saved in the browser, read the published
page back before regenerating, or those edits are lost.
